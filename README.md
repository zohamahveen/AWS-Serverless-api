# AWS Serverless API Project
This project demostrates how to build a simple serverless API using AWS Lambda and API Gateway.

## Services Used 
- AWS Lambda
- Amazon API Gateway
- Github
- Python

  ## How it works
  1. A Lamda function is created using Python.
  2. API Gateway exposes the Lambda function through a public HTTP endpoint.
  3. When the endpoint is accessed,the lambda function returns a message.
 
  ## API Endpoint
  https://dh9ljtzzk5.execute-api.us-east-1.amazonaws.com/default/zoha-serverless-api

  ## Architecture
  Client (Browser) -> API Gateway -> AWS Lamda -> Response
